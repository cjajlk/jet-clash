JETCLASH — ASSETS ARÈNE V3

Planche triée en 7 groupes sans modifier les PNG sources.
Les assets conservent leur transparence et leurs marges d'origine.

PRIORITÉ D'INTÉGRATION
1. 01_buts : cages bleue/rouge.
2. 02_structures : cadres, barrières et arches pour habiller les limites.
3. 03_sol : plaques de terrain.
4. 04_skyline : éléments décoratifs de fond uniquement.
5. 05_signaletique : bannières, néons, bornes et symboles.
6. 06_eclairage : projecteurs.
7. 07_fx : effets lumineux optionnels.

RÈGLE JEU
Ces images sont décoratives : ne pas modifier les collisions, les dimensions des buts, le plafond, les hitbox, le ballon ou la physique pour s'adapter aux PNG. Adapter uniquement le rendu des assets à la géométrie validée.
